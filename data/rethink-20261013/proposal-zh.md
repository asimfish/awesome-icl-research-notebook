# Learning When Corrections Should Generalize

当前是论文候选设计，不是已实现算法。11 个候选均留档；R1 更新交换路线被评为 RETHINK。本文件保留 CON-01“纠正的传播范围”作为下一项方法必要性诊断，状态 REVISE。神经训练、正式 query0、真机执行均未发生。评审同家族，接受与原创性判断仅 provisional。

## 不变的研究锚点

机器人能否从自己的纠正经验中学到可复用的任务关系，并把这些关系用于此前没有执行过的新目标？

## 论文故事与背景

机器人当前任务完成得更好，可能是找到绕路、记住路径或辨认训练内任务；这并不自动意味着它知道错误应怎样改变其他目标上的准备和顺序。已有自身历史保留实验节省 8.0799 个命令并提高 1.9586 个百分点完成率，只建立历史效用；原单 query completion gate 仍 FAILED，不能解释成关系学习。

更具体的问题是**纠正的传播范围**。贴标失败后夹紧零件才成功：机器人应该修正贴标条件，但是否也要改变对盖章、钻孔的准备？过度传播会给无关工具加前置操作，局部记忆又可能无法复用真实共享约束。一次记录未必能决定共享范围，正确模型须保留这种不确定性。

因此研究目标是：从自己的可见纠正经历判断哪个关系需要改、影响哪些命令、哪些已验证知识仍成立，然后在此前未执行的目标中使用这个判断。算法优势若成立，应同时体现在修正、复用和限制错误传播；不能仅报平均完成率或模块名称。

## 相对已有方法的边界

[PSGI](https://arxiv.org/pdf/2203.15034) 已有参数化任务结构复用；[OHCAM](https://arxiv.org/html/2608.30955v1) 已有自身后果驱动的条件扩展和主动消歧；[Twin](https://arxiv.org/html/2608.14490v1) 与 [PatchWorld](https://arxiv.org/html/2605.30880v1) 已有程序反例修补、旧经验重放。图、规则、共享结构与反例修补都不能独立成为贡献。

[IIT](https://proceedings.mlr.press/v162/geiger22a.html) / [Causal Distillation](https://arxiv.org/abs/2112.02505) 也覆盖干预结构蒸馏，不能靠“动态更新”摆脱直接前作。R1 两段网络与相同输入/标签 KD 的差别尚未建立，故撤回其当前主方法地位。

当前候选唯一待证的操作是：**一个可学习的修补根据证据选择共享 schema、局部例外或绑定改变，并仅在证据支持的范围传播**。层级 Bayes 与带共享结构的行动模型学习器已经具有相关能力，它们必须成为强基线。我们尚未知道该学习操作是否比这些方法更好、是否足够新。

## 数学 formulation

未知任务关系 M 在多个必需目标之间固定。每个 episode 可重置物理状态，知识上下文保留；未来目标由预声明分布产生，不提供隐藏任务图。

e_t=(o_t,a_t,o_{t+1},v_t)，H_t=(e_1,…,e_t)。m_{t+1}=Uθ(m_t,e_t)，a~πθ(·|o,g,m_t)。θ 在部署冻结；m 是可更新上下文，不是模型参数。未执行命令的真规则不能从不可辨识历史中被强制恢复。

候选表示：m=(Z,B,L,W)，Z 是共享关系 schema 状态，B 是由公共对象/命令角色推断的绑定，L 是局部例外，W 是带 ID 的真实证据。命令的关系预测 R_a=Decodeθ(Z,B_a,L_a)。Z/B/L 不是环境真图标签。只给可见 predicate 的先导时，所有基线得到相同 predicate；后续视觉/控制不由这个先导代替。

Uθ 提出有界候选更新 {δ_shared,δ_local,δ_binding}，分别改变共享条件、某命令例外、命令与 schema 的关联；一个共享改动可通过 B 影响未执行命令。候选根据同一真实历史的后果一致性评分；无法区分的候选保持多解。部署教师退出，编辑只改 m。若使用 top-K 近似必须报告截断和失效，不能把选中候选当关系真值。

对固定完整模型集合可以递推旧权重；对于刚由编辑产生的新模型，不能直接继承旧解释的后验。先将脚本解码并去重为完整 M_k，再按 pθ(M_k|H) ∝ pθ(M_k)∏_(e∈unique(H))pθ(e|M_k) 评分；抽样提议须有对应 proposal 校正。共享/局部/绑定编辑是提出解释，不是修改真实世界。这个后验目标属于既有推断；候选增量只能在共享范围提议/应用的学习和计算结构中建立。

## 训练与推理的最小设计

复用观察编码器、公共命令和策略头；新训练组件最多两个：共享 schema/binding encoder，有限修补提议器。当前尚无实现，不规定它们必然有用。

离线让学生产生实际成功、失败、恢复片段；监督只使用合法后果和自己的成功 continuation。训练时留出某命令的后果，由其他命令经历预测，迫使模型检验共享关系是否有预测价值。L=L_own_consequence+λ L_masked_command_consequence+β L_own_success_action+η L_edit_complexity。各目标应在所有相关基线中匹配；不能把多一项 auxiliary loss 误报成新更新操作。

推理：接收真实事件 → 提出共享/局部/绑定候选 → 检查既有真实证据 → 保留有权重的解释 → 策略在当前公开目标读出。只缓存真实事件一次，避免复制记录后重复计为独立证据。源后验不能覆盖接收既有知识；反事实训练结果不能混入部署历史。

当前最小信息诊断 SCOPE0 已检查“传播来自证据还是先验”：8个模型、4种合成记录、2个明示先验、64次评分，结果与解析后验一致。它不使用新模型、actor 或机器人。简单共享 Bayes 已给出主要定性行为；a2始终不唯一可辨识，方法必要性未成立。

随后完成 OPERATION_EQUIVALENCE_AUDIT.md：将旧解释按局部编辑搬运后验，会得到错误的 .82 而非条件化后的 .5；修正权重语义后，当前例中的编辑只是既有后验推断的提议方式。尚未指出学习型提议能省掉的具体计算，不进入训练。审查过的初稿保留于 FINAL_PROPOSAL.reviewed-v1.md，复评6.05仅对应该版，不当作修订后的接受证据。

## 三个决定性验证块

1. **信息与传播范围诊断。** 兼容模型集合中目标命令的规则是否唯一？分别检查共享证据、局部例外和不足以决定范围的记录。不可辨识时评价校准/决策分布，不能奖励猜中真实隐藏图。SCOPE0 是第一个精确 reference check，其余未执行。
2. **学习操作的增量。** 同一自身事件流、观察、共享结构、训练样本与计算，比较局部编辑、共享 schema 全历史重推断、层级 Bayes/参数化规则学习、历史策略及候选传播编辑。持出关系组合、绑定拓扑与局部例外；报告新目标 query0、既有关系退化、错误传播、总命令数、记忆与更新时间。去掉传播约束但保留全部教学输出的普通训练也必须比较。若强共享基线同样解决，就撤回该主算法主张。
3. **物理后果与总成本。** 只有前两块显示增量，才用现有 CPU MuJoCo 做含共享准备关系与局部例外的操作链。分开偶发动作失败与关系错误，记录实际准备、失败、reset、探测和更新成本；测试独立 reset 下的未执行组合目标。旧 12000 次 body-force 推方块不支持本方法，也不构成具身验证。真机/大模型评测需后续资源，当前不声称已完成。

## 放弃条件与当前结论

若绑定依赖真实 scope 标签、未知关系上只靠教师泄漏、相同历史有矛盾真值目标、共享 Bayes/规则推断复制全部收益、或收益仅来自更长历史/更多数据，则不能写成新算法论文。若局部修正改善但未影响命令大量退化，同样失败。

本轮推进的是把“大系统怎样自我改进”收窄成“纠正应该怎样泛化”的可检验算法问题，并排除两类看似新颖的旧操作。候选尚未建立方法必要性或新颖性；不把 REVISE、评审分数或解析反例写成结果贡献。
